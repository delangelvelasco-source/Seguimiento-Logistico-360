# Control de cambios

1. Todo cambio de aplicación se realiza mediante GitHub.
2. Los cambios deben tener un mensaje de commit descriptivo.
3. La compilación de producción se ejecuta antes del despliegue.
4. Los cambios de base de datos se aplican mediante migraciones versionadas en Supabase.
5. Los cambios de seguridad deben documentar su objetivo y alcance.
6. Los incidentes o regresiones deben generar un cambio correctivo trazable.
7. Para producción empresarial, se recomienda incorporar revisión/aprobación previa del responsable de IT antes de cambios críticos.
